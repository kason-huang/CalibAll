The user explicitly requested model and data-reading integration first because
joint units are unknown. Calibration is blocked by SO101TF until the mapping
is confirmed. The evaluator's angles_in_degrees=true is not proof of recording
units: LeRobot SO101 defaults to [-100,100] body normalization and [0,100]
gripper normalization. Do not turn on SO101_STATE_UNITS merely to bypass this.
Use radians/degrees only when ALL six inputs truly represent URDF joint angles.
Normalized values need motor calibration, sign/zero mapping, and gripper mapping.
TCP uses the URDF gripper_frame_link; physical grasp-axis semantics are not yet
independently validated. Flange tracking reference uses gripper_link.

LeRobot v3 reader handles shared data files by episode_index, and shared videos
using per-episode from_timestamp. No dataset conversion or overwrite occurs.
Tests: independent RoboticsToolbox FK comparison at two poses, all visual files,
unknown-unit guard, decoding episodes 0 and 1 (including nonzero video offset),
and Web DatasetBuilder construction. See test_so101_adapter.py.
